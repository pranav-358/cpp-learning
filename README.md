# C++ Learning Repository

This repository contains the C++ programs and practice exercises I have completed while learning C++ programming. It serves as a record of my progress and helps me organize the concepts I learn.

## Upcoming Topics

* Pointers
* Object-Oriented Programming (OOP)
* STL Containers
* File Handling
* Data Structures and Algorithms

## Running the Programs

Clone the repository:

```bash
git clone https://github.com/pranav-358/cpp-learning.git
```

Go to the required folder:

```bash
cd your-repo-name
```

Compile the program:

```bash
g++ filename.cpp -o output
```

Run the program:

**Linux/macOS**

```bash
./output
```

**Windows**

```bash
output.exe
```

The purpose of this repository is to practice C++ programming and keep track of my learning progress. New programs and concepts will be added as I continue learning.
