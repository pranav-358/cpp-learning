## Running the Programs

Clone the repository:

```bash
git clone https://github.com/pranav-358/cpp-learning.git
```

Go to the required folder:

```bash
cd your-repo-name
```

Compile the program:

```bash
g++ filename.cpp -o output
```

Run the program:

**Linux/macOS**

```bash
./output
```

**Windows**

```bash
output.exe
```
